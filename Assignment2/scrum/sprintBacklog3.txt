TYPE     : BUG BUG3.001 : phanale5 : Completed
NAME     : Oval drawing implementation is limited
PRIORITY : 2
ESTIMATE : 1 hour    ACTUAL : 10 minutes
ISSUE    : The current implementation of Oval allows a user to specify the top left
           corner of an oval and drag downward and to the right to create it. However, when a
           user attempts to drag their mouse in another direction, no oval or an incorrect
           oval is drawn.

TYPE     : BUG BUG3.004 : ahme1250 : Completed
NAME     : Architecture behind Model is poor
PRIORITY : 3
ESTIMATE : 3 hours    ACTUAL : 5 hours
ISSUE    : Having a list of different types of drawable things in the
           model is cumbersome. In fact, it is currently incorrect, with
           Squiggle's not drawing properly. Need to re-architect the Model
           so that it is more flexible, and easier to work with.
           Consider some design patterns, or change of responsibility
           here.

--------------------------------------------------------------------------
TYPE     : BUG BUG3.005 : ahme1250 : Completed
NAME     : Square drawing restricted to one direction
PRIORITY : 2
ESTIMATE : 2 hours    ACTUAL : 10 minutes
ISSUE    : Currently, squares can only be drawn by clicking the top-left
           corner and dragging downwards and to the right. The drawing
           logic does not allow users to drag in any direction (e.g., up or
           left). Need to adjust coordinate and dimension calculations in
           SquareTool so users can draw squares freely in all directions.
--------------------------------------------------------------------------
--------------------------------------------------------------------------
TYPE     : BUG BUG3.006 : ahme1250 : Completed
NAME     : Rectangle drawing restricted to one direction
PRIORITY : 2
ESTIMATE : 10 minutes    ACTUAL : 10 minutes
ISSUE    : Currently, rectangles can only be drawn by clicking the top-left
           corner and dragging downwards and to the right. The drawing
           logic does not allow users to drag in any direction (e.g., up or
           left). Need to adjust coordinate and dimension calculations in
           RectangleTool so users can draw rectangles freely in all
           directions, maintaining correct width and height regardless of
           drag direction.
