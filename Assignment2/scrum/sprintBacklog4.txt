TYPE     : BUG BUG4.010 : ahme1250 : Completed
NAME     : Command Pattern Not Implemented (Undo/Redo Non-Functional)
PRIORITY : 3
ESTIMATE : 1 hour   ACTUAL : 45 minutes
ISSUE    : The paint application did not support Undo or Redo because the
           executeCommand() method and command-history system were not
           implemented. Actions such as drawing, moving, or editing shapes
           were not recorded as Commands and therefore could not be undone
           or redone. Implementing executeCommand(), undo(), redo(), and
           proper command stacks resolved the issue and restored expected
           editor functionality.

TYPE     : BUG BUG4.011 : ahme1250 : Completed
NAME     : Shortcut Keys Not Displayed / Keyboard Shortcuts Not Working
PRIORITY : 2
ESTIMATE : 45 minutes   ACTUAL : 1.25 hours
ISSUE    : Tool buttons did not display their assigned keyboard shortcuts,
           causing unclear UI feedback and inconsistent tool selection.
           Additionally, several keyboard shortcuts such as Ctrl+X (Cut),
           Ctrl+C (Copy), Ctrl+V (Paste), Ctrl+Z (Undo), Ctrl+Y (Redo),
           and Delete (Clear Canvas) were not being detected by the system,
           leading to user actions not activating the correct commands.

           Fixes included:
           • Updating ShapeChooserPanel so each button displays its shortcut
             in brackets (e.g., "Circle (C)", "SelectMove (M)").
           • Adding a global KeyEvent filter in View to properly detect
             Ctrl-modified shortcuts and trigger corresponding actions.
           • Ensuring both tool selection shortcuts and edit shortcuts
             (Undo, Redo, Cut, Copy, Paste, Delete) work consistently.
